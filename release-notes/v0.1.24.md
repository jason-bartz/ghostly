A new icon
- Ghostly has a new app icon and mark. The ghost stays, but it is now drawn as real vector artwork instead of a scaled-up image, so it stays sharp everywhere from the Dock to a 16-pixel Finder list.
- The menu bar icon has been redrawn to match, with clearer recording and transcribing states.

Light mode fixes
- Several screens were showing light-mode colours on the dark theme, including the log folder, the app data folder and the debug paths. They now follow whichever theme you are using.
- Warnings, errors and success messages across the app now flip properly between Light and Dark, so they stay readable in both.

Polish
- Moving between screens now transitions instead of snapping.
- Loading placeholders shimmer rather than blink, and progress bars that cannot report a percentage now sweep instead of pulsing.
- Buttons no longer show a focus ring when you click them with the mouse, matching the rest of macOS. Keyboard navigation still shows it.
